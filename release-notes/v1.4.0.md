## 🇵🇱 Polski

### SCP Escape System 1.4.0

Wydanie naprawia rozliczanie ucieczek, transfer SCP-079 i zachowanie pluginu przy współpracy z innymi pluginami.

- Sukces SCP jest zapisywany dopiero po potwierdzonej zmianie w Chaos Conscript. Zablokowana zmiana klasy nie daje fałszywego zwycięstwa ani broadcastu.
- Droga ucieczki otwiera się po zakończonej fali z żywymi graczami MTF/Chaos. Anulowane i puste fale jej nie odblokowują.
- Ludzie są liczeni po potwierdzonej ucieczce; anulowana próba nie wymusza remisu.
- SCP-079 jest sprawdzany po zakończonych śmierciach, zmianach klas i rozłączeniach. Wcześniejsza udana ucieczka SCP nadal jest wymagana.
- Ucieczki SCP nie zwiększają natywnego licznika uciekających Class-D.
- Przeładowanie pluginu zachowuje stan bieżącej rundy. Restart unieważnia stare, oczekujące operacje.
- Zarejestrowane CustomRoles są usuwane po konwersji bez uruchamiania ich domyślnej śmierci przy usunięciu.
- Dodano walidację konfiguracji, ograniczenie częstotliwości hintów i ponowień oraz zdarzenia integracyjne `ScpEscaping` i `ScpEscaped`.
- Dodano 38 testów regresji, CI i instrukcję budowania. Domyślna reguła wyniku rundy pozostaje bez zmian.

### Instalacja / aktualizacja

1. Usuń poprzednią DLL tego pluginu, także jeśli nazywa się `SCPRUN.dll`.
2. Pobierz **`ScpEscapeSystem.dll`** z załączników i umieść ją w `EXILED/Plugins`.
3. Upewnij się, że dostępny jest moduł `Exiled.CustomRoles`, i zrestartuj serwer.
4. Zachowaj istniejącą sekcję `scp_escape_system`. Nowe ustawienia to `allow_custom_roles`, `escape_retry_seconds` i `locked_hint_interval`.

Integracje anulujące ucieczkę SCP powinny używać `Plugin.Instance.ScpEscaping`. Konwersja SCP jest oddzielona od natywnych ucieczek ludzi.

### Weryfikacja i zgodność

38/38 testów na symulowanym API przeszło lokalnie i w GitHub Actions. Kompilacja: .NET Framework 4.8, AnyCPU na dostępnych bibliotekach EXILED 9.12.6; dodatkowo x64 na 9.13.2. Załączona DLL to wariant AnyCPU/9.12.6.

Build zgłasza MSB3277 dotyczące wersji netstandard 2.0/2.1 w referencjach; szczegóły są w `BUILDINFO.json` i `docs/BUILD.md`. Nie wykonano testu na działającym serwerze/klientach, w tym na EXILED 9.15.2. Sprawdzenia wymagają natywny recontainment SCP-079 i sprzątanie modeli/umiejętności własnych SCP.

Załączniki: DLL, `SHA256SUMS.txt` oraz `BUILDINFO.json`.

## 🇬🇧 English

### SCP Escape System 1.4.0

This release fixes escape accounting, SCP-079 transfer checks and interactions with other plugins.

- An SCP escape is committed only after a confirmed Chaos Conscript conversion. Denied class changes no longer award false victories or success broadcasts.
- The escape route opens after a completed wave with actual living MTF/Chaos players. Cancelled or empty waves do not unlock it.
- Humans are counted after confirmed escapes; cancelled attempts no longer force a draw.
- SCP-079 is re-evaluated after completed deaths, class changes and disconnects. At least one earlier successful SCP escape is still required.
- SCP conversions no longer increase the native escaped Class-D counter.
- Plugin reloads preserve the current round's state. Round resets invalidate stale pending operations.
- Registered CustomRoles are removed after conversion without triggering their default removal death.
- Added config validation, hint/retry throttling and the `ScpEscaping` / `ScpEscaped` integration events.
- Added 38 regression tests, CI and build instructions. The default round-result rule is unchanged.

### Installation / update

1. Remove the old plugin DLL, including an old copy named `SCPRUN.dll`.
2. Download **`ScpEscapeSystem.dll`** from the assets and place it in `EXILED/Plugins`.
3. Ensure `Exiled.CustomRoles` is installed and restart the server.
4. Keep the existing `scp_escape_system` configuration. New settings are `allow_custom_roles`, `escape_retry_seconds` and `locked_hint_interval`.

Integrations that deny SCP escapes should use `Plugin.Instance.ScpEscaping`. SCP conversion is separate from the native human escape pipeline.

### Validation and compatibility

38/38 simulated-API regression tests passed locally and in GitHub Actions. Builds: .NET Framework 4.8, AnyCPU against available EXILED 9.12.6 references, plus x64 against 9.13.2. The attached DLL is the AnyCPU/9.12.6 build.

The build reports MSB3277 for a netstandard 2.0/2.1 reference mismatch; see `BUILDINFO.json` and `docs/BUILD.md`. No live server/client session was run, including on EXILED 9.15.2. Native SCP-079 recontainment and custom SCP model/ability cleanup still need a server smoke test.

Assets: the plugin DLL, `SHA256SUMS.txt` and `BUILDINFO.json`.
